- **Status:** In review

## Scope

**Goal:** Add a Host-only, human-reviewed AI Description Assistant to New/Edit listing forms without changing listing persistence semantics.

**In scope:** F1–F8, N1–N7, E1–E22 from the approved spec.

**Non-goals:** Automatic listing saves; schema or migration changes; direct browser-to-SoCLaaS calls; client API keys; free-form prompt instructions; streaming, history, caching, or multi-instance limiter changes; amendments to W-AI-GATEWAY; broader PII detection, deterministic factual-grounding, moderation, or endpoint idempotency.

**Risk tier:** High — Host-authored text and listing data cross the backend-to-LLM boundary, so verification must cover authorization, prompt boundaries, output validation, safe errors, and draft-preserving UI behavior.
