**Key snippet — GuestExceptionHandler error mapping (SD9):**

Controllers check ownership before calling service methods. When ownership fails, throw `ForbiddenException` (not `IllegalArgumentException`), so the handler maps it to 403. The service's own ownership check is defence-in-depth and would produce a 400 if somehow reached — the controller pre-empts it.

```java
// ForbiddenException.java
public class ForbiddenException extends RuntimeException {
    public ForbiddenException(String message) { super(message); }
}

// GuestExceptionHandler.java — complete mapping
@ExceptionHandler(ForbiddenException.class)
ResponseEntity<Map<String, String>> handleForbidden(ForbiddenException ex) {
    return error(403, "FORBIDDEN", ex.getMessage());
}

@ExceptionHandler(IllegalArgumentException.class)
ResponseEntity<Map<String, String>> handleIllegalArg(IllegalArgumentException ex) {
    String msg = ex.getMessage() != null ? ex.getMessage() : "";
    int status = 400; String code = "BAD_REQUEST";
    if (msg.contains("does not exist"))         { status = 404; code = "LISTING_NOT_FOUND"; }
    else if (msg.contains("is not active"))     { code = "LISTING_INACTIVE"; }
    else if (msg.contains("not available"))     { status = 409; code = "DATES_UNAVAILABLE"; }
    else if (msg.contains("Cannot book your own")) { code = "SELF_BOOKING"; }
    else if (msg.contains("Start and end dates")) { code = "VALIDATION_ERROR"; }
    else if (msg.contains("End date must be"))  { code = "INVALID_DATE_RANGE"; }
    return error(status, code, msg);
}

@ExceptionHandler(IllegalStateException.class)
ResponseEntity<Map<String, String>> handleIllegalState(IllegalStateException ex) {
    String msg = ex.getMessage() != null ? ex.getMessage() : "";
    int status = 400; String code = "BAD_REQUEST";
    if (msg.contains("Cannot cancel"))          { code = "NOT_CANCELLABLE"; }
    else if (msg.contains("not eligible for a dispute")) { code = "DISPUTE_WINDOW_CLOSED"; }
    else if (msg.contains("already exists for this booking") && msg.contains("ticket")) { status = 409; code = "DUPLICATE_TICKET"; }
    else if (msg.contains("already exists for this booking") && msg.contains("review")) { status = 409; code = "DUPLICATE_REVIEW"; }
    else if (msg.contains("Ticket is resolved") || msg.contains("Chat is closed")) { code = "THREAD_CLOSED"; }
    else if (msg.contains("only be submitted for completed")) { code = "NOT_REVIEWABLE"; }
    else if (msg.contains("Insufficient") || msg.contains("insufficient")) { code = "INSUFFICIENT_BALANCE"; }
    return error(status, code, msg);
}

private ResponseEntity<Map<String, String>> error(int status, String code, String message) {
    return ResponseEntity.status(status).body(Map.of(
        "code", code, "message", message, "requestId", UUID.randomUUID().toString()));
}
```

**Key snippet — trip grouping logic (SD8):**
```java
private TripGroup groupOf(Booking b, LocalDate today) {
    BookingStatus s = b.getStatus();
    if (s == BookingStatus.PENDING || (s == BookingStatus.CONFIRMED && b.getStartDate().isAfter(today))) {
        return TripGroup.UPCOMING;
    }
    if (s == BookingStatus.CONFIRMED && !b.getStartDate().isAfter(today) && !b.getEndDate().isBefore(today)) {
        return TripGroup.ACTIVE;
    }
    return TripGroup.PAST; // COMPLETED, FORCE_COMPLETED, FORCE_CANCELLED, REJECTED, CANCELLED_*, or CONFIRMED past end
}
```
