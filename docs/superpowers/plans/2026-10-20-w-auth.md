# W-AUTH Implementation Plan

> **For agents:** tick each checklist item as it is completed. Keep the branch-state Progress cell current. Spec: [W-AUTH design](../specs/2026-10-20-w-auth-design.md).

## Scope

**Goal:** Add Firebase-backed identity, database-owned roles, secure registration, and client-side protected auth flows.

**In scope:** Firebase Admin verification, Spring Security, V002 auth schema, registration and `/me`, configuration registration codes, Firebase JS client, AuthProvider, auth screens, route guards, tests.

**Non-goals:** OAuth/MFA/phone auth, custom claims, role feature pages, domain-service porting, AI, payments, production secret provisioning and session cookies.

**Risk tier:** High — authentication, authorization, personal data and wallet provisioning require security, concurrency and integration evidence.
