# Edge Cases and Non-Happy Paths

| ID | Requirement | Scenario | Expected behaviour (exact) | Why it matters | Test layer |
|---|---|---|---|---|---|
| E1 | F1, N1 | A paragraph still tells users to install Java, run Gradle, copy a SQLite database, or launch a JAR | The paragraph is removed or rewritten as an explicitly non-user developer note; no desktop startup instruction remains in the user guide | Prevents users from following an unusable setup path | manual documentation review |
| E2 | F2, N1 | Authentication text describes email-only login, fixed sign-up keys as the whole auth model, or mocked authentication | The text describes Firebase-backed email/password authentication, registration, password reset, and role codes where implemented | Prevents incorrect account expectations | manual documentation review |
| E3 | F3, N1 | A documented route, role action, AI feature, label, or limitation cannot be found in the current frontend/backend or state record | The claim is removed, or is explicitly labeled `Planned — not available in the current web app`; an unverified claim is never left without that exact qualification | Prevents guide drift from the shipped web app | source cross-check |
| E4 | F4, N2 | An internal anchor points to a removed heading, or a retained screenshot path is accidentally deleted | The anchor resolves to a current heading and the image reference remains syntactically valid | Keeps the Jekyll page navigable while screenshots are deferred | link/path check |
| E5 | N1 | A feature is planned but not implemented, such as Agent AI | The guide omits it or labels it as unavailable; it is not presented as a current user workflow | Prevents documenting roadmap behavior as shipped behavior | manual documentation review |
| E6 | F2, N1 | A registration-code example is copied from a local/demo setting into production instructions | The guide says Host and Agent codes are supplied by the administrator and does not expose production secrets | Prevents publishing privileged credentials | source cross-check |
| E7 | F1, N2 | The guide's current deployed URL differs from the verified runbook URL | The guide uses the runbook URL and labels it as the current deployment entry point | Prevents users being sent to an invented or obsolete host | source cross-check |
| E8 | F3, N1 | A retained screenshot shows the retired desktop UI | Its caption or adjacent prose contains the exact replacement marker and makes no claim that the image is current | Prevents visual misinformation while screenshots are deferred | manual documentation review |
